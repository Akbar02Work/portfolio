Область: Business, `creative/`, общие данные и ресурсы, `public/creative/`, сборка,
скрипты, тесты и статическая конфигурация Vercel. Исходное рабочее дерево было чистым.

- `npm run ci:full` — линтеры Business/Creative и JS-скриптов, поиск циклов,
  TypeScript обоих приложений, **52/52 unit**, **4/4 интеграционных теста скриптов**,

- `playwright test --browser=firefox` — **22/22**; `--browser=webkit` — **22/22**.
  Всего 66 успешных браузерных сценариев в трёх движках.
- `npm audit` и `npm --prefix creative audit` — **0 уязвимостей** в обоих деревьях
  на момент проверки. Это не гарантия отсутствия неизвестных уязвимостей.
- `git diff --check` — успешно. Итоговый diff проверен, изменения ограничены
  этим репозиторием и задачей. Генерируемые Creative assets соответствуют исходникам.
- Просмотрены снимки реальных viewport: Business и VoiceNotes на desktop/mobile,
  планшетное меню, Creative с обычным/reduced motion и мобильный gate. В проверенных
  сценариях нет page errors, битых изображений или горизонтального переполнения.
  Локальные диагностические артефакты находятся в игнорируемом `test-results/`.

Для быстрого скролла учитывается ограничение Firefox на размер одного wheel delta:
тест дополнительно выполняет End, сохраняя проверку скачка и стабильности высоты.

## Сохранённые решения и границы уверенности

- Различия дизайна Business/Creative, desktop-only Creative и скрытый Lumingo
  сохранены. Android/Web/iOS-кейс проверен на изолированном fixture без публикации.
- Существующие React 18/19 и две сборочные границы не объединялись: доказанной
  необходимости такой миграции нет. Полезные тесты и рабочая галерея сохранены;
  лишний глобальный обработчик удалён вместо переписывания carousel.
- `public/old/`, CV, фотографии и скриншоты проектов не изменены. В текущем архивном
  HTML уже есть `noindex, nofollow`. Запрет robots сам по себе не гарантирует
  исчезновения ранее известных URL из поискового индекса.
- Статическое сканирование отслеживаемых исходников и имён файлов не обнаружило
  actionable-секретов. Git history, внешние секрет-хранилища и production env не
  сканировались; контакты/CV являются намеренно публичным содержимым.
- Локальные проверки не доказывают actual Vercel edge routing, CDN caching,
  привязку домена, внешние ссылки, приём событий Sentry/Speed Insights и состояние
  поискового индекса. Нужен отдельный smoke после согласованного deploy. Текущий
  scope не разрешает deploy или изменение сервисов.
- CSP оставлен ограничительным; без фактического production DSN нельзя доказать,
  что разрешены все используемые региональные Sentry ingest-хосты. Ослабление
  политики без этого доказательства не выполнялось.
- Headless WebKit/Firefox/Chromium не заменяют Safari/iOS/Android на устройстве,
  screen reader-аудит или GPU-профилирование. WebGL по-прежнему требует отдельного
  замера на слабых устройствах и проверки потери GPU context.
- Prerender создаёт route-specific метаданные, а не SSR всего React-контента.
  Полная работоспособность страниц без JavaScript не заявляется.
- При установке остаются deprecation notices транзитивных dev-зависимостей jsdom
  (`abab`, `domexception`, `whatwg-encoding`); тесты проходят и audit чист. Major
  миграция тестового окружения ради предупреждений не выполнялась.

Для сверки модели статического деплоя использована
[официальная документация Vercel](https://vercel.com/docs/project-configuration/vercel-json).
Настройки самого проекта Vercel в рамках аудита не менялись.
